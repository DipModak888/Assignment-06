# 💪 FitLog — Workout Library

A dark, no-nonsense gym companion: pick a lift, lock it into today's plan, and watch the week's work add up.

## Technologies
Next.js (App Router) · React · TypeScript · Tailwind CSS · lucide-react · Oswald + Inter (next/font)

## Features
1. Responsive workout library (3-column grid → 1 column) fed by the FitLog API, with a loading animation.
2. Workout details page with key specs, instructions and Add to plan / Save for later actions.
3. My Plan page with live Exercises / Minutes / Calories metrics and Today's Plan / Saved tabs.
4. Mark as Done, remove, and Sort By (Duration, Calories, Rating) with toast notifications.
5. Navbar badges that update live; plan and saved lists persist in localStorage (5-lift cap).
6. Custom 404 page and dark, Figma-matched UI.
